# Capitole speciale de sisteme de operare - Temele mele

## Obiective:
Acest curs oferă o aprofundare a mecanismelor de bază din sistemele de operare și se concentrează pe topici avansate despre modulele nucleului sistemului de operare Windows. Conceptele sunt prezentate pe baza curiculei dezvoltate de Microsoft Windows Academic Program, structurată în conformitate cu ACM/IEEE Operating System Body of Knowledge.

## Descriere repository:
Acest depozit conține temele și notițele mele pentru disciplina "Capitole speciale de sisteme de operare". Fiecare temă este organizată într-un director separat și include codurile sursă, fișierele de laborator, documentațiile și referințele folosite.

## Structură propusă:
- tema-01/   - Tema 1: titlu și fișiere
- tema-02/   - Tema 2: titlu și fișiere
- resurse/   - materiale suplimentare, linkuri și articole
- README.md  - acest fișier

## Cum folosesc acest repo:
1. Deschide directorul temei care te interesează (ex: tema-01)
2. Consultă enunțul, codul și documentația din acel director
3. Pentru rulare sau compilare, urmează instrucțiunile din fișierele README specifice fiecărei teme
